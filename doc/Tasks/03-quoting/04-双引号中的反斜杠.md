## 双引号中的反斜杠

在这一阶段，你将实现对双引号内反斜杠的支持。

### 双引号中的反斜杠

在[双引号](https://www.gnu.org/software/bash/manual/bash.html#Double-Quotes)内，反斜杠只能转义某些特殊字符：`"`、`\`、`$`、`` ` `` 和换行符。对于所有其他字符，反斜杠被视为字面字符。

在这一阶段，我们将介绍：

- `\"`：转义双引号，允许 `"` 作为字面字符出现在引号字符串内
- `\\`：转义反斜杠，结果是字面的 `\`

我们不会在这一阶段介绍以下情况：

- `\$`：转义美元符号
- `` \` ``：转义反引号
- `\<newline>`：转义换行字符

以下是一些说明双引号内反斜杠行为的示例：

| 命令 | 预期输出 |
| :--------------------------------: | :------------------------: |
| `echo "A \\ escapes itself"` | `A \ escapes itself` |
| `echo "A \" inside double quotes"` | `A " inside double quotes` |

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送一系列 `echo` 命令：

```bash
$ echo "just'one'\\n'backslash"
just'one'\n'backslash
$ echo "inside\"literal_quote."outside\"
inside"literal_quote.outside"
```

测试程序会检查 `echo` 命令是否正确打印了带引号的文本。

然后它还会发送一个 `cat` 命令，文件名称参数由双引号内的反斜杠组成：

```bash
$ cat /tmp/"number 1" /tmp/"doublequote \" 2" /tmp/"backslash \\ 3"
content1 content2 content3
```

测试程序会检查 `cat` 命令是否正确打印了文件内容。
