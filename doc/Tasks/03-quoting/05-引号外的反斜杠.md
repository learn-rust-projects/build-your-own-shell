## 引号外的反斜杠

在这一阶段，你将实现对引号外反斜杠的转义支持。

### 反斜杠转义

当反斜杠 `\` 在引号外使用时，它充当转义字符。反斜杠会移除下一个字符的特殊含义，并将其视为字面字符。转义后，反斜杠本身会被移除。

这适用于任何字符，包括：
- 具有特殊含义的字符（如空格、`'`、`"`、`$`、`*`、`?` 及其他分隔符）
- 没有特殊含义的字符（如 `n`、`t` 等常规字母）

以下是一些说明引号外反斜杠行为的示例：

| 命令 | 预期输出 | 说明 |
|---------|----------------|-------------|
| `echo three\ \ \ spaces` | `three   spaces` | 每个 `\ ` 创建一个字面空格作为单个参数的一部分 |
| `echo before\     after` | `before  after` | 反斜杠保留第一个空格为字面，但 shell 会合并后续未转义的空格 |
| `echo test\nexample` | `testnexample` | `\n` 变成只是 `n` |
| `echo hello\\world` | `hello\world` | 第一个反斜杠转义第二个，结果是参数中包含单个字面反斜杠 |
| `echo \'hello\'` | `'hello'` | `\'` 使单引号成为字面字符 |

### 测试

测试程序会这样执行你的程序：
```bash
$ ./your_program.sh
```

然后它会向你的 shell 发送一系列 `echo` 命令：
```bash
$ echo multiple\ \ \ \ spaces
multiple    spaces
$ echo \'\"literal quotes\"\'
'"literal quotes"'
$ echo ignore\_backslash
ignore_backslash
```

测试程序会检查 `echo` 命令是否正确处理了转义字符。

接下来，测试程序会发送一个 `cat` 命令，文件名参数中使用反斜杠来转义字符：

```bash
$ cat /tmp/\_ignored_1 /tmp/ignore_\2 /tmp/just_one_\\_3
content1 content2 content3
```

测试程序会验证 `cat` 命令是否正确访问了这些文件。
