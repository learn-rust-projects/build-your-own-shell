## 双引号

在这一阶段，你将实现对双引号的引号支持。

### 双引号

在 shell 语法中，[双引号](https://www.gnu.org/software/bash/manual/bash.html#Double-Quotes)（`"`）内的大多数字符都被视为字面字符。但是双引号允许某些特殊字符被解释（如 `$` 用于变量，`\` 用于转义），我们将在后续阶段介绍这些例外。

在这一阶段，你的 shell 在解析双引号时必须应用以下规则：

- 连续的空白字符（空格、制表符）必须被保留
- 通常用作分隔符或特殊字符的字符在双引号内会失去其特殊含义，被视为字面字符
- 相邻的双引号字符串会被连接起来形成单个参数
  - 引号和无引号的字符串相邻时也会被连接

例如：

```bash
$ echo "hello    world"
hello    world         # 多个空格被保留

$ echo "hello""world"
helloworld             # 相邻的引号字符串被连接

$ echo "hello"world
helloworld             # 引号和无引号的字符串相邻时被连接

$ echo "hello" "world"
hello world            # 单独的参数

$ echo "shell's test"
shell's test           # 内部的单引号是字面字符
```

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送一系列 `echo` 命令：

```bash
$ echo "quz  hello"  "bar"
quz  hello bar
$ echo "bar"  "shell's"  "foo"
bar shell's foo
$
```

测试程序会检查 `echo` 命令是否正确打印了带引号的文本。

接下来，测试程序会发送一个 `cat` 命令，文件名称参数用双引号括起来：

```bash
$ cat "/tmp/file name" "/tmp/'file name' with spaces"
content1 content2
```

测试程序会检查 `cat` 命令是否正确打印了文件内容。
