## 单引号中的反斜杠

在这一阶段，你将实现对单引号内反斜杠的引号支持。

### 单引号中的反斜杠

[单引号](https://www.gnu.org/software/bash/manual/bash.html#Single-Quotes)内的反斜杠没有特殊的转义行为。单引号内的每个字符（包括反斜杠）都被视为字面字符。

例如：

```bash
$ echo 'shell\\\nscript'
shell\\\nscript

$ echo 'example\"test'
example\"test
```

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送一系列 `echo` 命令：

```bash
$ echo 'multiple\\slashes'
multiple\\slashes
$ echo 'every\"thing_is\"literal'
every\"thing_is\"literal
```

测试程序会检查 `echo` 命令是否正确打印了带引号的文本。

接下来，测试程序会发送一个 `cat` 命令，文件名称参数由单引号内的反斜杠组成：

```bash
$ cat /tmp/'no slash 1' /tmp/'one slash \2' /tmp/'two slashes \3\'
content1 content2 content3
```

测试程序会检查 `cat` 命令是否正确打印了文件内容。
