## 单引号

在这一阶段，你将实现对单引号的引号支持。

### 单引号

[单引号](https://www.gnu.org/software/bash/manual/bash.html#Single-Quotes)（`'`）会**禁用其中所有字符的特殊含义。单引号内的每个字符都被视为字面字符。**

当你的 shell 解析命令行时：

- 单引号内的字符（包括转义字符和潜在的特殊字符如 `$`、`*` 或 `~`）会失去其特殊含义，被视为普通字符
- 单引号内连续的空白字符（空格、制表符）会被保留，不会被合并或用作分隔符
- 相邻的引号字符串会被连接起来形成单个参数

以下是一些说明单引号行为的示例：

|          命令           |     预期输出     |                      说明                      |
| :---------------------: | :--------------: | :--------------------------------------------: |
| `echo 'hello    world'` | `hello    world` |               引号内的空格被保留               |
|  `echo hello    world`  |  `hello world`   |        连续的空格会被合并，除非使用引号        |
|  `echo 'hello''world'`  |   `helloworld`   | 相邻的引号字符串 `'hello'` 和 `'world'` 被连接 |
|   `echo hello''world`   |   `helloworld`   |               空引号 `''` 被忽略               |

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送一系列 `echo` 命令：

```bash
$ echo 'shell hello'
shell hello
$ echo 'world     test'
world     test
$
```

测试程序会检查 `echo` 命令是否正确打印了带引号的文本。

然后它还会发送一个 `cat` 命令，文件名称参数用单引号括起来：

```bash
$ cat '/tmp/file name' '/tmp/file name with spaces'
content1 content2
```

测试程序会检查 `cat` 命令是否正确打印了文件内容。

### 注意事项

- `cat` 命令是大多数系统上可用的可执行文件，所以不需要你自己实现它
