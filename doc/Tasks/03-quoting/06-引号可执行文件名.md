## 引号可执行文件名

在这一阶段，你将实现对带引号的可执行文件名的支持。

### 引号可执行文件名

到目前为止，可执行文件名（命令中的第一个词）一直是简单字符串。但可执行文件名也可以像参数一样带引号。当可执行文件名包含空格、引号或特殊字符时，这很有用。

对可执行文件名加引号让你可以执行否则难以引用的程序。

例如：

```bash
$ 'my program' argument1
# 运行名为 "my program" 的可执行文件

$ "exe with spaces" file.txt
# 运行名为 "exe with spaces" 的可执行文件
```

当你的 shell 收到带有引号可执行文件的命令时：

- 你的解析器必须正确解释引号以形成可执行文件名（例如，从 `"my 'program'"` 到 `my 'program'`）
- 你的 shell 必须在 `PATH` 目录中搜索不带引号的程序名
- 找到可执行文件后，你的 shell 必须派生进程并将其他标记作为参数传递

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送一系列命令，执行重命名的 `cat` 可执行文件：

```bash
$ 'exe with "quotes"' file
content1
$ "exe with 'single quotes'" file
content2
```

测试程序会验证：
- 带引号的可执行文件名被正确处理（引号被移除）
- 生成的可执行文件名被找到并执行
- 输出与可执行文件产生的结果匹配
