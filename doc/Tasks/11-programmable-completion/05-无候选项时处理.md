## 无候选项时处理

在这一阶段，你将处理补全脚本返回无候选项的情况。

### 处理空补全输出

当补全脚本向 stdout 什么都不打印时，你的 shell 没有候选项可以使用。在这种情况下，shell 应该：

- 保持输入不变
- 通过向 stdout 打印 `\x07` 按终端铃

这给用户反馈：他们的 TAB 按键被接收但没有可用的补全。

例如，一个补全脚本总是退出而不打印任何内容：

```python
#!/usr/bin/env python3
exit(0)
```

当注册并用 TAB 触发时，你的 shell 应该只是按铃并保持输入不变：

```bash
$ complete -C /path/to/completer_script docker
$ docker xyz<TAB>
# 铃响，输入行保持为 "docker xyz"
```

### 测试

测试程序会这样执行你的程序：

```bash
$ ./your_program.sh
```

它将提供一个什么都不打印的补全脚本，为命令注册它，然后按 TAB：

```bash
$ complete -C /path/to/completer_script docker
$ docker xyz<TAB>
# 铃响，输入不变
```

测试程序会验证：

- TAB 按键后输入行保持不变
- 铃字符（`\x07`）被打印到 stdout
