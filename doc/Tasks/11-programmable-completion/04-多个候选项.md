## 多个候选项

在这一阶段，你将处理补全脚本返回多个候选项的情况。

### 多个候选项

补全脚本可以通过向 stdout 单独打印每一行来返回多个候选项。

例如，如果补全脚本打印：

```
add
commit
push
```

而用户按 TAB 两次：

```bash
$ git <TAB><TAB>
add  commit  push
$ git
```

1. 第一次 TAB 应该按终端铃（因为没有唯一补全）
2. 第二次 TAB 应该在下一行显示所有候选项，按字母顺序排序，间隔至少一个空格（建议两个空格以提高可读性）

显示候选项后，shell 应该重新打印带有原始输入的提示符。

### 测试

测试程序会这样执行你的程序：

```bash
$ ./your_program.sh
```

然后它会注册一个始终返回三个候选项（`add`、`commit`、`push`）的补全脚本：

```bash
$ complete -C /path/to/completer_script git
$ git <TAB><TAB>
add  commit  push
$ git
```

测试程序会验证：

- 第一次 TAB 按铃（没有唯一匹配）
- 第二次 TAB 在一行上显示所有候选项，间隔至少一个空格
- 候选项按字母顺序排序
- 候选项列表后重新打印提示符和原始输入

### 注意事项

- 你还不需要实现最长公共前缀（LCP）补全。我们将在后续阶段介绍
