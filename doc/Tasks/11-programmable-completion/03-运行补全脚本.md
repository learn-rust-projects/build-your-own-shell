## 运行补全脚本

在这一阶段，你将调用注册的补全脚本并使用其输出来补全单个候选项。

### 运行补全脚本

在前面的阶段中，你用 `complete -C` 注册了补全脚本并存储了它们。现在你将实际运行它们。

当用户输入命令名后跟一个空格并按 TAB 时，你的 shell 应该首先检查是否为该命令注册了补全器。如果已注册：

1. 将脚本作为单独进程运行
2. 读取其 stdout
3. 将输出的每一行作为一个补全候选项

如果没有注册补全器，你的 shell 应该回退到其现有的补全行为（或者如果还没有实现其他补全逻辑，则不执行任何操作）。

在这一阶段，补全器将始终恰好打印一行。你的 shell 应该获取该行并用补全后的内容以及尾随空格来补全用户的输入。

例如，一个补全脚本可以像这样简单：

```python
#!/usr/bin/env python3
print("run")
```

当注册并用 TAB 触发时，你的 shell 应该运行脚本，读取其 stdout，并使用输出作为补全：

```bash
$ complete -C /path/to/completer_script docker
$ docker <TAB>
$ docker run
```

### 测试

测试程序会这样执行你的程序：

```bash
$ ./your_program.sh
```

它将创建一个始终向 stdout 打印单个单词的补全脚本，为命令注册它，然后按 TAB：

```bash
$ complete -C /path/to/completer_script <command>
$ <command> <TAB>
$ <command> <candidate>
```

测试程序会验证：
- 你的 shell 在 TAB 时运行注册的补全脚本
- stdout 的单行用作补全
- 补全后添加尾随空格

### 注意事项

- 你还不需要将补全上下文（如当前正在输入的单词）传递给补全器。那将在后续阶段介绍
- 确保在插入补全前等待补全脚本完成，否则你可能读取部分输出
- 补全脚本可以用任何语言编写。你的 shell 只需要执行它并从 stdout 读取
