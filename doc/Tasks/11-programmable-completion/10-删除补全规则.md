## 删除补全规则

在这一阶段，你将添加使用 `complete -r` 删除补全规则的支持。

### -r 选项

`complete` 内置命令接受 `-r` 标志，后跟命令名。这删除该命令的任何存储补全规则。删除后，按 TAB 应该表现得好像从未注册过补全一样。

```bash
$ complete -C /path/to/completer_script git
$ git ch<TAB>
$ git checkout             # 补全有效

$ complete -r git
$ git ch<TAB>              # 铃响，无补全
```

命令成功时不产生输出。

### 测试

测试程序会这样执行你的程序：

```bash
$ ./your_program.sh
```

它会注册一个补全，用 `-r` 注销它，通过 `-p` 确认规则消失，然后再次尝试补全。

```bash
$ complete -C /path/to/completer_script git
$ complete -r git
$ complete -p git
complete: git: no completion specification
# 预期：铃响
$ git <TAB>
```

测试程序会验证：
- 注销后 `complete -p git` 打印 `complete: git: no completion specification`
- `git` 的 Tab 补全不再有效，铃响

### 注意事项

- 如果 `complete -r` 被调用一个没有注册补全的命令，shell 应该仍然不产生输出，不要将其视为错误
