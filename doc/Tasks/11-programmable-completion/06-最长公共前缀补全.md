## 最长公共前缀补全

在这一阶段，当多个候选项共享一个前缀时，你将补全到最长公共前缀（LCP）。

### 最长公共前缀补全

当补全器返回多个候选项时，有两种情况需要处理：

- 如果它们共享的前缀长于当前输入：补全到 LCP
- 如果没有：在第一次 tab 时按铃，在后续 tab 按键时列出匹配项（与前一阶段相同）

例如，如果补全器返回 `checkout` 和 `cherry-pick`，用户输入了 `c`：

```bash
$ git c<TAB>
$ git che
```

两个候选项都以 `che` 开头，所以 shell 补全到 `che` 并等待更多输入。不按铃，不显示候选项列表。

### 测试

测试程序会这样执行你的程序：

```bash
$ ./your_program.sh
```

它将注册一个返回 `checkout` 和 `cherry-pick` 的补全脚本：

```bash
$ complete -C /path/to/completer_script git
$ git c<TAB>
$ git che                  # checkout 和 cherry-pick 的 LCP
$ git chec<TAB>
$ git checkout             # 现在只有一个匹配，完全补全带尾随空格
```

测试程序会验证：

- 当存在最长公共前缀时，第一次 TAB 补全到最长公共前缀
- 当只剩一个候选项时，TAB 用尾随空格完全补全完整单词
- 当 LCP 扩展当前输入时，不按铃

### 注意事项

- LCP 是根据补全器返回的候选项计算的，而不是从硬编码列表计算的
- 如果 LCP 等于用户已经输入的内容（没有新字符要添加），将其视为没有公共前缀相同：按铃并在下一个 TAB 上显示候选项
