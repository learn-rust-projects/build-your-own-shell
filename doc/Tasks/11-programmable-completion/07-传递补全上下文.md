## 传递补全上下文

在这一阶段，你将把补全上下文作为命令行参数传递给 `-C` 补全脚本。

### 向补全器传递参数

补全脚本需要知道用户正在输入什么才能提供相关建议。当你的 shell 调用用 `complete -C` 注册的补全器时，它应该传递恰好三个参数：

1. `argv[1]` — 正在补全的命令名（例如 `git`）
2. `argv[2]` — 当前正在补全的单词（光标处的部分文本）
3. `argv[3]` — 正在补全单词之前的单词。如果没有前面的单词，传递空字符串

补全脚本使用这些值来决定打印到 stdout 的候选项（每行一个，与之前相同）。

例如，给定这个命令行：

```bash
$ git remote set<TAB>
```

你的 shell 应该用以下参数调用补全脚本：

- `argv[1]`: `git`（命令）
- `argv[2]`: `set`（正在补全的单词）
- `argv[3]`: `remote`（前一个单词）

补全脚本然后可以使用 `argv[2]` 通过前缀过滤其候选项（例如，返回 `set-url` 因为它以 `set` 开头）。

### 测试

测试程序会这样执行你的程序：

```bash
$ ./your_program.sh
```

它会为命令注册一个补全脚本：

```bash
$ complete -C /path/to/completer_script git
```

然后它会输入部分参数并按 TAB：

```bash
$ git remote set<TAB>
$ git remote set-url
```

补全脚本只有在你正确传递 `argv[1]`、`argv[2]` 和 `argv[3]` 的值时才会返回正确的候选项。

测试程序会验证：

- 补全脚本将命令名作为 `argv[1]` 接收
- 补全脚本将正在补全的部分单词作为 `argv[2]` 接收
- 补全脚本将前一个单词作为 `argv[3]` 接收
- 补全的单词替换部分文本并添加尾随空格

### 注意事项

- 补全脚本已经由测试程序编写。你不需要创建它，只需用正确的参数调用它
- 如果正在补全的单词之前没有单词（例如 `git <TAB>`），传递空字符串作为 `argv[3]`
