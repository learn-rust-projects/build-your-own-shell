## 声明和显示变量

在这一阶段，你将添加对存储和显示 shell 变量的支持。

### 声明 shell 变量

使用 `declare NAME=VALUE`，shell 记录一个 shell 变量及其值。使用 `declare -p NAME`，shell 打印描述该变量的一行。`declare -p NAME` 的输出是 `declare -- NAME="VALUE"`。

例如：

```bash
$ declare foo=bar
$ declare -p foo
declare -- foo="bar"
```

### 测试

测试程序会这样执行你的程序：

```bash
$ ./your_program.sh
```

然后它会用 `declare` 定义一个变量并请求其描述：

```bash
$ declare foo=bar
$ declare -p foo
declare -- foo="bar"
$ declare -p missing_variable
declare: missing_variable: not found
$ declare foo=bar2
$ declare -p foo
declare -- foo="bar2"
```

测试程序会验证现有变量和非存在变量的输出格式是否匹配预期。
