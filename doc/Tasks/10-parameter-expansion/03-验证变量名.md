## 验证变量名

在这一阶段，你将添加对 shell 变量名验证的支持。

### 验证标识符

shell 变量名必须是有效标识符：它以字母或下划线开头，名称的其余部分可以使用字母、数字和下划线。

数字不能是第一个字符。如果名称无效，shell 报告错误且不创建变量。

例如：

```bash
# 有效的变量声明
$ declare foo=bar
$


# 有效的变量声明
$ declare _FOO=BAR
$


# 无效的变量
$ declare 67=x
declare: `67=x': not a valid identifier
$
```

### 测试

测试程序会这样执行你的程序：

```bash
$ ./your_program.sh
```

它会发送带有有效名称（以字母或 `_` 开头）和无效名称（例如以数字开头）的 `declare`。对于无效名称，测试程序会验证输出如下：

```bash
$ declare 23=x
declare: `23=x': not a valid identifier
$ declare _FOO=bar
$ declare -p _FOO
declare -- _FOO="bar"
```
