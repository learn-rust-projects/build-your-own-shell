## 未设置变量的展开

在这一阶段，你将添加对展开未设置变量名的支持。

### 展开中未设置的名称

当变量未设置时，它展开为空字符串 — 它对单词没有贡献。它周围的任何字面文本仍然保留。

```bash
$ declare greeting=hello
$ echo ${greeting}world
helloworld
$ echo ${missing}world
world
```

`${missing}` 未设置，所以它展开为 nothing，只剩下 `world`。

### 测试

测试程序会这样执行你的程序：

```bash
$ ./your_program.sh
```

它会声明 `existing`，不设置 `missing1` 和 `missing2`，然后运行：

```bash
$ declare existing=existingsvalue
$ ./custom_exe_1234 ${missing1}end ${existing} ${missing2}
Program was passed 3 args (including program name).
Arg #0 (program name): custom_exe_1234
Arg #1: end
Arg #2: existingsvalue
Program Signature: 5998595441
```

注意 `${missing2}` 展开为没有周围文本的空字符串，所以 shell 产生一个空单词并完全丢弃它 — 不会传递第三个参数。

测试程序会验证子进程在程序名后恰好接收到那些参数。
