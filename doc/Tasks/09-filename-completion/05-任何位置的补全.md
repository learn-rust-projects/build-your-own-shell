## 任何位置的补全

在这一阶段，你将扩展 tab 补全以适用于任何参数位置。

### 任何位置的补全

到目前为止，你的 shell 补全命令后的第一个参数。

在这一阶段，补全应该对任何后续参数以相同的方式工作：
- 提取最后一个空格后的文本
- 在当前工作目录中匹配它
- 使用相同的规则补全（LCP、多个匹配时按铃、尾随空格/斜杠）

例如，在当前目录中有 `foo`（文件）和 `bar/`（目录）时：
```bash
$ ls b<TAB>
# 补全为 bar/（目录，无尾随空格）
$ ls bar/

# 用户输入空格和 f
$ ls bar/ f<TAB>
# 补全为 foo（文件，带尾随空格）
$ ls bar/ foo

# 用户输入空格和 x
$ ls bar/ foo x<TAB>
# 无匹配，铃响，输入不变
$ ls bar/ foo x
```

### 测试

测试程序会在当前目录创建条目（例如 `foo` 和 `bar/`）并这样执行你的程序：
```bash
$ ./your_program.sh
```

然后它在不同参数位置测试补全：
```bash
$ ls <TAB><TAB>
bar/  foo
$ ls

$ ls b<TAB>
$ ls bar/

$ ls bar/ f<TAB>
$ ls bar/ foo

$ ls bar/ foo x<TAB>
$ ls bar/ foo x
```

测试程序会验证：
- 第一个参数的补全正常工作
- 后续参数的补全正常工作
- 任何位置的无匹配行为（铃响）都正常工作
- 所有先前的补全功能（LCP、多个匹配等）在任何位置都正常工作

### 注意事项

- 每个参数独立地在当前工作目录中补全。前面的目录参数（如 `bar/`）不会改变后续参数的搜索目录。例如，在 `ls bar/ f<TAB>` 中，`f` 在 CWD 中匹配，而不是在 `bar/` 内部
- 所有先前阶段的补全逻辑适用于每个参数位置
