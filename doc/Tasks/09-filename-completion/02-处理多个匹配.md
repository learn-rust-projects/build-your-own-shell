## 处理多个匹配

在这一阶段，你将处理条目有多个匹配时的 tab 补全。

### 处理多个匹配

当多个文件或目录匹配当前前缀时：
1. 第一次 `<TAB>`：按铃（`\x07`）以指示存在多个匹配
2. 后续 `<TAB>` 按键：按字母顺序在新行上列出所有匹配，然后在重新显示提示符

列出匹配项时：
- 用至少一个空格分隔条目（建议两个空格以提高可读性）
- 用尾随 `/` 显示目录
- 不带任何尾随字符显示文件

例如，条目为 `bar.txt` 和 `foo/` 时：
```bash
$ stat <TAB>
# 铃响，输入不变
$ stat <TAB>
bar.txt  foo/
$ stat
```

由于原始输入保留在提示符上，用户可以继续输入以缩小匹配范围。

### 测试

测试程序会创建多个条目（例如 `bar.txt` 和 `foo/`）并这样执行你的程序：
```bash
$ ./your_program.sh
```

然后它会模拟用户输入：
```bash
$ stat <TAB><TAB>
bar.txt  foo/
$ stat
```

测试程序会验证：
- 第一次 tab 按键按铃
- 后续 tab 按键显示所有匹配条目：
  - 匹配项按字母顺序排序
  - 匹配项间隔至少一个空格
  - 目录用尾随 `/` 显示
  - 匹配项显示在新行上
- 提示符重新出现，原始输入被保留
