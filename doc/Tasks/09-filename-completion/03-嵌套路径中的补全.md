## 嵌套路径中的补全

在这一阶段，你将添加对嵌套路径中文件名补全的支持。

### 嵌套路径中的补全

到目前为止，你的 shell 只补全当前目录中的文件名。现在你将扩展它，以便在用户包含路径时补全子目录中的文件。

例如，如果有一个文件在 `path/to/file.txt`，用户可以输入：

```bash
$ cat path/to/f<TAB>
$ cat path/to/file.txt
#                      ^ 注意尾随空格
```

### 实现路径补全

当用户按 tab，且部分文件名包含 `/` 时：

1. 在最后一个 `/` 字符处拆分文本：
   - 到并包括最后一个 `/` 的所有内容是目录路径
   - 其后的所有内容是要匹配的前缀

   例如，在 `path/to/f` 中，目录路径是 `path/to/`，前缀是 `f`
2. 在目录路径中搜索以该前缀开头的条目
3. 如果一个条目匹配，用完整路径替换整个部分文件名并添加尾随空格（例如 `path/to/f` 变为 `path/to/file.txt `）

### 测试

测试程序会在嵌套目录（例如 `path/to/file.txt`）中创建一个文件并这样执行你的程序：

```bash
$ ./your_program.sh
```

然后它会模拟用户输入和 tab 按键：

```bash
$ cat path/to/f<TAB>
$ cat path/to/file.txt
```

测试程序会验证：
- 按 tab 补全部分路径到完整路径
- 补全路径后添加尾随空格

### 注意事项

- 目录路径是相对于当前工作目录的。例如，如果当前工作目录是 `/home/user` 且标记是 `path/to/f`，则在 `/home/user/path/to/` 内部列出条目
- 你只需要处理恰好一个条目匹配前缀的情况。我们将在后续阶段处理多个匹配
