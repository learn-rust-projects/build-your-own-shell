## 目录名补全

在这一阶段，你将添加对补全目录名的支持。

### 目录名补全

到目前为止，你的 shell 补全文件名和文件路径。现在你将扩展它以补全目录。

目录补全帮助用户导航到子目录，而无需输入完整路径。

当用户按 `<TAB>` 且匹配是目录时：
1. 用匹配的目录名补全标记
2. 附加尾随 `/` 但不带空格

例如：

```bash
$ cd proj<TAB>
$ cd project/
#           ^ 注意尾随斜杠（无空格）
```

尾随 `/` 让用户可以立即再次按 tab 来补全路径的下一级。

更多示例：

```bash
# 示例 1：补全目录
$ rmdir p<TAB>
$ rmdir pig/

# 示例 2：补全进入目录
$ rmdir pig/<TAB>
$ rmdir pig/dog/
```

在第二个示例中，用户已经输入了 `pig/`，然后按 tab 补全为 `pig/dog/`。

### 测试

测试程序会创建嵌套目录（例如 `pig/dog/`）并这样执行你的程序：

```bash
$ ./your_program.sh
```

然后它会模拟用户输入：

```bash
$ ls <TAB>
$ ls pig/
$ ls pig/<TAB>
$ ls pig/dog/
```

测试程序会验证：
- 命令后的第一次 tab（如 `ls `）补全到第一个目录，带尾随斜杠
- 第二次 tab 补全到嵌套目录，带尾随斜杠
- 斜杠后不添加尾随空格

### 注意事项

- 你只需要处理恰好一个条目匹配的情况。我们将在后续阶段处理多个匹配
- 文件和目录补全都应该工作。文件带尾随空格，目录带尾随斜杠不带空格
- 你可以使用语言的文件系统函数检查条目是否为目录（例如 Python 中的 `os.path.isdir()`、Node.js 中的 `fs.statSync().isDirectory()`）
