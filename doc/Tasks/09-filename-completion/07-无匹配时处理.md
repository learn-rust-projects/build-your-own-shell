## 无匹配时处理

在这一阶段，你将处理参数与任何条目都不匹配的情况。

### 无匹配补全

当用户输入与任何条目都不匹配的参数并按 `<TAB>` 时，你的 shell 应该：
1. 保持输入不变（不要修改用户输入的内容）
2. 打印铃字符 `\x07` 到标准输出

[铃字符](https://en.wikipedia.org/wiki/Bell_character) 通常根据终端设置产生可听到的蜂鸣声或可视闪烁。

例如：
```bash
$ cat absent_filenam<TAB>
# 不发生补全，输入不变
# 铃字符 (\x07) 打印到 stdout
$ cat absent_filenam
```

### 测试

测试程序会这样执行你的程序：

```bash
$ ./your_program.sh
```

然后它会模拟带有不存在路径的用户输入：

```bash
$ cat absent_filenam<TAB>
$ cat absent_filenam
```

测试程序会验证：
- 当没有补全可能时输入保持不变
- 铃字符被打印到标准输出
