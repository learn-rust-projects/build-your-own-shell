## 文件名补全

在这一阶段，你将添加对文件名补全的支持。

### 文件名补全

文件名补全是 shell 的一个功能，通过按 `<TAB>` 键帮助用户补全文件名参数。

例如：

```bash
$ cat re<TAB>
$ cat readme.txt
#                ^ 注意尾随空格
```

当用户在输入参数时按 `<TAB>` 时：

1. 提取输入中最后一个空格后的文本（例如 `"cat re"` 中的 `"re"`）
2. 在当前目录中搜索以该前缀开头的文件
3. 如果有文件匹配，补全它并添加尾随空格

尾随空白让用户可以立即开始输入下一个参数，而无需手动添加空格。

### 测试

测试程序会在当前目录创建一个文件（例如 `readme.txt`）并这样执行你的程序：

```bash
$ ./your_program.sh
```

然后它会模拟带有部分文件名的用户输入：

```bash
$ cat re<TAB>
$ cat readme.txt

$ cat hello<TAB>
$ cat hello_world.py
```

测试程序会验证：

- 按 tab 补全部分文件名到完整文件名
- 文件名后添加尾随空格

### 注意事项

- 在这一阶段，你只需要将前缀与当前工作目录中的文件匹配。我们将在后续阶段实现嵌套目录中的补全
- 在这一阶段，你只需要处理单个匹配文件名的情况。我们将在后续阶段实现目录补全和多个补全
- 补全适用于任何命令，而不仅仅是 `cat`。例如，即使对于不存在的命令如 `xyz`，按 tab 仍应补全参数：`xyz read<TAB>` 变为 `xyz readme.txt `
