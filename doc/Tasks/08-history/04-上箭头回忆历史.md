## 上箭头回忆历史

在这一阶段，你将添加支持使用上箭头键回忆历史的功能。

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送多个命令，然后是上箭头键来回忆历史：

```bash
$ echo hello
hello
$ echo world
world
<UP ARROW>
$ echo world
<UP ARROW>
$ echo hello
```

测试程序会期望当按下上箭头键时显示先前的命令。

### 注意事项

- 对于 Rust 实现，推荐使用 [rustyline](https://crates.io/crates/rustyline/) 库。大多数现代 shell 和 REPL（如 Python REPL）在后台使用 [GNU readline](https://www.wikiwand.com/en/articles/GNU_Readline)。虽然你可能需要重写其一些默认行为，但这通常比从头开始实现工作量更少
- 对于 Python 实现，推荐使用 [readline](https://docs.python.org/3/library/readline.html) 模块
- 对于 Go 实现，推荐使用 [readline](https://pkg.go.dev/github.com/chzyer/readline) 库
- 对于 Java 实现，推荐使用 [JLine](https://github.com/jline/jline3) 库
- 对于 C# 实现，推荐使用 [Readline.Ext](https://www.nuget.org/packages/ReadLine.Ext) 库
