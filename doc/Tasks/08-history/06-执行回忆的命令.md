## 执行回忆的命令

在这一阶段，你将添加支持按回车键执行使用上箭头和下箭头回忆的命令。

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送多个命令，然后是上箭头然后下箭头键来回忆历史，然后按回车执行命令：

```bash
$ echo hello
hello
$ echo world
world
<UP ARROW>
$ echo world
<UP ARROW>
$ echo hello
<DOWN ARROW>
$ echo world
<ENTER>
world
$
```

测试程序会期望当按回车键时命令被执行。
