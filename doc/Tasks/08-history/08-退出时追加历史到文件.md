## 退出时追加历史到文件

在这一阶段，你将添加支持在退出时将内存中的历史追加到历史文件。

### 测试

测试程序会向历史文件写入以下命令：

```txt
echo initial_command_1
echo initial_command_2
<|EMPTY LINE|>
```

测试程序会这样执行你的程序：

```bash
HISTFILE=<path_to_history_file> ./your_program.sh
```

然后它会向你的 shell 发送以下命令：

```bash
$ echo new_command
new_command
$ exit
```

然后测试程序会期望历史文件的内容如下：

```txt
echo initial_command_1
echo initial_command_2
echo new_command
exit
<|EMPTY LINE|>
```
