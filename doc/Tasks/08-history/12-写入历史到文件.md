## 写入历史到文件

在这一阶段，你将添加支持使用 `history -w <path_to_history_file>` 命令将内存中的命令写入历史文件。

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送以下命令：

```bash
$ echo hello
hello
$ echo world
world
$ history -w <path_to_history_file>
$
```

然后测试程序会期望历史文件的内容如下：

```txt
echo hello
echo world
history -w <path_to_history_file>
<|EMPTY LINE|>
```

### 注意事项

- 如果在运行 `history -w` 时文件不存在，你的 shell 应该创建文件然后将命令写入其中
- 测试程序会期望 `history -w` 命令也出现在历史文件中
- 历史文件应包含尾随换行符（显示为空行）
