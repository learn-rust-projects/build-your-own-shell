## 限制历史条目数量

在这一阶段，你将添加支持限制历史条目数量的功能。

### `history <n>` 命令

`history` 命令可以带一个可选的数字参数来限制显示的条目数量。当用户运行 `history <n>` 时，你的 shell 应该显示历史记录中的最后 `n` 条命令。

例如，`history 2` 显示最近的两条命令：

```bash
$ echo first
first
$ echo second
second
$ history 2
    2  echo second
    3  history 2
$
```

这里，`history 2` 命令显示最近的两条命令（包括 `history` 命令本身）。

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送多个命令，然后是 `history <n>` 命令：

```bash
$ echo hello
hello
$ echo world
world
$ invalid_command
invalid_command: command not found
$ history 2
    3  invalid_command
    4  history 2
$
```

测试程序会验证：
- 输出显示最后 `n` 条命令
- 每个条目编号正确
- `history` 命令本身出现在历史记录中

### 注意事项

- `history` 命令应该将其自身包含在历史列表中
- 在 Bash 中，`history <n>` 表示"显示最后 n 条命令"。一些 shell 如 zsh 对此解释不同（作为"从第 n 行开始显示条目"），但对于这个挑战，使用 Bash 的解释
