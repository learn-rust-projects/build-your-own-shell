## 追加历史到文件

在这一阶段，你将添加支持使用 `history -a <path_to_history_file>` 命令将内存中的命令追加到历史文件。

### 测试

测试程序会向历史文件写入以下命令：

```txt
echo initial_command_1
echo initial_command_2
<|EMPTY LINE|>
```

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送以下命令：

```bash
$ echo new_command
new_command
$ history -a <path_to_history_file>
$
```

然后测试程序会期望历史文件的内容包含新命令：

```txt
echo initial_command_1
echo initial_command_2
echo new_command
history -a <path_to_history_file>
<|EMPTY LINE|>
```

### 注意事项

- 测试程序会期望 `history -a` 命令也出现在历史文件中
- 多次运行 `history -a` 应该只追加自上次 `history -a` 以来执行的命令
