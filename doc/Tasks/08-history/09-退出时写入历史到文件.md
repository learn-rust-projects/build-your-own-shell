## 退出时写入历史到文件

在这一阶段，你将添加支持在退出时将内存中的历史写入历史文件。

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送以下命令：

```bash
$ echo hello
hello
$ echo world
world
$ exit
```

然后测试程序会期望历史文件的内容如下：

```txt
echo hello
echo world
exit
<|EMPTY LINE|>
```
