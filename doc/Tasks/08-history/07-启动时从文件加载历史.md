## 启动时从文件加载历史

在这一阶段，你将确保你的 shell 在启动时从文件加载历史到内存中。

### `HISTFILE` 环境变量

[`HISTFILE` 环境变量](https://www.gnu.org/software///bash/manual/bash.html#index-HISTFILE) 指定历史文件的路径。它是用于在启动时从文件加载历史到内存以及在退出时将内存中的历史保存到文件的路径。

### 测试

测试程序会向历史文件写入以下命令：

```txt
echo hello
echo world
<|EMPTY LINE|>
```

测试程序会这样执行你的程序：

```bash
HISTFILE=<path_to_history_file> ./your_program.sh
```

然后它会向你的 shell 发送以下命令：

```bash
$ history
    1  echo hello
    2  echo world
    3 history
$
```
