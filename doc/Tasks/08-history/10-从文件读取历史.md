## 从文件读取历史

在这一阶段，你将使用 `history -r <path_to_history_file>` 命令从文件读取历史。

### 测试

测试程序会向历史文件写入以下命令：

```txt
echo hello
echo world
<|EMPTY LINE|>
```

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送以下命令：

```bash
$ history -r <path_to_history_file>
$ history
    1  history -r <path_to_history_file>
    2  echo hello
    3  echo world
    4  history
$
```

### 注意事项

- 测试程序会期望历史命令也出现在历史列表中
- `history -r` 应该将历史文件的内容追加到内存中的历史列表
