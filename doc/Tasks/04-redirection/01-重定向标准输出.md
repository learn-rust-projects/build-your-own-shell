## 重定向标准输出

在这一阶段，你将实现将命令输出重定向到文件的支持。

### `>` 操作符

`>` 操作符将命令的标准输出重定向到文件。当你使用 `>` 时，通常出现在终端上的输出会被写入指定文件。

如果文件不存在，则创建它。如果文件已存在，则被覆盖（替换其旧内容）。

例如：

```bash
$ echo hello > output.txt
$ cat output.txt
hello
```

### 文件描述符表示法

在 Unix 中，标准输出用数字 `1` 标识。你可以显式地写 `1>` 来重定向标准输出：

```bash
$ echo hello 1> file.txt
```

但是，由于重定向标准输出非常常见，shell 允许你省略 `1` 而只写 `>`：

```bash
$ echo hello > file.txt
```

这两个命令的作用完全相同。

### 错误输出不会被重定向

`>` 操作符只重定向标准输出，不重定向标准错误。如果命令产生错误消息，它们仍然会显示在终端上：

```bash
$ cat nonexistent > output.txt
cat: nonexistent: No such file or directory
$ cat output.txt
$
```

错误消息出现在终端上，`output.txt` 是空的（或者如果有任何非错误输出，则只包含非错误输出）。

### 测试

测试程序会这样执行你的程序：
```bash
$ ./your_program.sh
```

然后它会向你的 shell 发送一系列命令并将其输出重定向到文件：

```bash
$ ls /tmp/baz > /tmp/foo/baz.md
$ cat /tmp/foo/baz.md
apple
blueberry

$ echo Hello James 1> /tmp/foo/foo.md
$ cat /tmp/foo/foo.md
Hello James

$ cat /tmp/baz/blueberry nonexistent 1> /tmp/foo/quz.md
cat: nonexistent: No such file or directory
$ cat /tmp/foo/quz.md
blueberry
```

测试程序会验证：
- 带 `>` 的命令将其标准输出重定向到指定文件
- 带 `1>` 的命令与 `>` 的作用完全相同
- 文件在不存在时会被创建
- 错误消息仍然显示在终端上（不会被重定向）
- 只有标准输出被写入文件
