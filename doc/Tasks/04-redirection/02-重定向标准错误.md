## 重定向标准错误

在这一阶段，你将实现将命令的标准错误重定向到文件的支持。

### `2>` 操作符

`2>` 操作符将命令的标准错误重定向到文件。标准错误是程序写入错误消息和诊断信息的地方。

在 Unix 中，标准错误用数字 `2` 标识。当你写 `2>` 时，你是在显式地将文件描述符 2（stderr）重定向到文件。

例如：

```bash
$ cat nonexistent 2> errors.txt
$ cat errors.txt
cat: nonexistent: No such file or directory
```

这里，错误消息被写入 `errors.txt` 而不是出现在终端上。

### 标准输出不会被重定向

`2>` 操作符只重定向标准错误，不重定向标准输出。正常输出仍然显示在终端上：

```bash
$ cat existing_file nonexistent 2> errors.txt
contents of existing file
$ cat errors.txt
cat: nonexistent: No such file or directory

$ echo hello 2> errors.txt
hello
$ cat errors.txt
$
```

在上面的示例中，文件内容出现在终端上，而任何错误消息都进入 `errors.txt`。

### 测试

测试程序会这样执行你的程序：
```bash
$ ./your_program.sh
```

然后它会向你的 shell 发送一系列命令并尝试将其标准错误重定向到文件：
```bash
$ ls nonexistent 2> /tmp/quz/baz.md
$ cat /tmp/quz/baz.md
ls: nonexistent: No such file or directory

$ echo Maria file cannot be found 2> /tmp/quz/foo.md
Maria file cannot be found
$ 

$ cat /tmp/bar/pear nonexistent 2> /tmp/quz/quz.md
pear
$ cat /tmp/quz/quz.md
cat: nonexistent: No such file or directory
```

测试程序会验证：
- 带 `2>` 的命令将其标准错误重定向到指定文件
- 指定文件在不存在时会被创建
- 标准输出仍然显示在终端上（不会被重定向）
- 标准错误不会显示在终端上
