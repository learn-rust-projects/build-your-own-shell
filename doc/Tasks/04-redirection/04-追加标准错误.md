## 追加标准错误

在这一阶段，你将实现将命令的标准错误追加到文件的支持。

### `2>>` 操作符

`2>>` 操作符将命令的标准错误追加到文件。与覆盖文件的 `2>` 不同，`2>>` 将错误消息添加到文件末尾并保留任何现有内容。

如果文件不存在，则会创建它。如果文件已存在，则新错误输出被添加到末尾。

例如：

```bash
$ cat nonexistent1 2>> errors.txt
$ cat nonexistent2 2>> errors.txt
$ cat errors.txt
cat: nonexistent1: No such file or directory
cat: nonexistent2: No such file or directory
```

### 测试

测试程序会这样执行你的程序：

```bash
$ ./your_program.sh
```

然后它会向你的 shell 发送一系列命令并将其标准错误追加到文件：

```bash
$ ls nonexistent >> /tmp/foo/baz.md
ls: nonexistent: No such file or directory

$ ls nonexistent 2>> /tmp/foo/qux.md
$ cat /tmp/foo/qux.md
ls: nonexistent: No such file or directory

$ echo James says Error 2>> /tmp/foo/quz.md
James says Error

$ cat nonexistent 2>> /tmp/foo/quz.md
$ ls nonexistent 2>> /tmp/foo/quz.md
$ cat /tmp/foo/quz.md
cat: nonexistent: No such file or directory
ls: nonexistent: No such file or directory
```

测试程序会验证：
- 带 `2>>` 的命令将其标准错误追加到指定文件
- 现有文件内容被保留（不会被覆盖）
- 标准输出仍然显示在终端上（不会被重定向）
- 文件在不存在时会被创建
