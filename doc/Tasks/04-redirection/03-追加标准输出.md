## 追加标准输出

在这一阶段，你将实现将命令输出追加到文件的支持。

### `>>` 操作符

`>>` 操作符将命令的标准输出追加到文件。与覆盖文件的 `>` 不同，`>>` 将输出添加到文件末尾并保留任何现有内容。

如果文件不存在，则会创建它（与 `>` 相同）。如果文件已存在，则新输出被添加到末尾。

例如：
```bash
$ echo first >> output.txt
$ echo second >> output.txt
$ cat output.txt
first
second
```

你也可以显式地写 `1>>` 来将命令的标准输出追加到文件。`>>` 和 `1>>` 的作用完全相同。

### 测试

测试程序会这样执行你的程序：
```bash
$ ./your_program.sh
```

然后它会向你的 shell 发送一系列命令并尝试将其输出追加到文件：
```bash
$ ls /tmp/baz >> /tmp/bar/bar.md
$ cat /tmp/bar/bar.md
apple
banana
blueberry

$ echo Hello Emily 1>> /tmp/bar/baz.md
$ echo Hello Maria 1>> /tmp/bar/baz.md
$ cat /tmp/bar/baz.md
Hello Emily
Hello Maria

$ echo List of files: > /tmp/bar/qux.md
$ ls /tmp/baz >> /tmp/bar/qux.md
$ cat /tmp/bar/qux.md
List of files:
apple
banana
blueberry
```

测试程序会验证：
- 带 `>>` 的命令将其标准输出追加到指定文件
- 带 `1>>` 的命令与 `>>` 的作用完全相同
- 现有文件内容被保留（不会被覆盖）
- 文件在不存在时会被创建
