## 多个可执行文件补全

在这一阶段，你将为共享公共前缀的多个可执行文件实现 tab 补全。

### 处理多个匹配

当用户输入命令前缀并按 `<TAB>` 时，你的 shell 应该找到 PATH 中匹配该前缀的所有可执行文件，并执行以下操作：

1. 第一次按 `<TAB>` 时，按铃（使用 `\x07`）
2. 第二次按 `<TAB>` 时：
   - 在新行上打印所有匹配的可执行文件。按**字母顺序**排列，间隔至少一个空格（建议两个空格以提高可读性）
   - 在下一行重新显示提示符，保持原始命令前缀

例如：

```bash
$ xyz_<TAB><TAB>
xyz_bar  xyz_baz  xyz_quz
$ xyz_
```

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会设置一个特定的 `PATH`，并将多个以公共前缀开头的可执行文件放置在 `PATH` 中的不同目录中。

最后，它会输入公共前缀，然后按两次 tab 键。

```bash
$ xyz_<TAB><TAB>
xyz_bar  xyz_baz  xyz_quz
$ xyz_
```

测试程序会验证：
1. 第一次 tab 按键按铃
2. 第二次 tab 按键按字母顺序显示所有匹配的可执行文件
   - 匹配项间隔至少一个空格
   - 匹配项显示在新行上
3. 提示符重新出现，原始输入被保留
