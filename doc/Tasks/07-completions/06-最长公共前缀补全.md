## 最长公共前缀补全

在这一阶段，你将扩展自动补全以使用最长公共前缀（LCP）逻辑处理部分补全。

### 补全到最长公共前缀

当多个可执行文件匹配用户的输入，而其中一些是其他的前缀时，你的 shell 应该补全到所有匹配的最长公共前缀。

例如，如果 PATH 中存在这些可执行文件：

- `xyz_foo`
- `xyz_foo_bar`
- `xyz_foo_bar_baz`

当用户输入 `xyz_` 并按 tab 时，shell 补全为 `xyz_foo`，因为这是所有三个可执行文件共享的最长前缀。

在用户输入下一个分隔符字符后，按 tab 补全到剩余匹配项的下一个公共前缀：

```bash
# 注意：下面的提示符行显示在同一行上
$ xyz_<TAB>
$ xyz_foo_<TAB>
$ xyz_foo_bar_<TAB>
$ xyz_foo_bar_baz
```

如果执行补全后只有一个匹配项，那么 shell 应该像前一阶段那样补全命令名（带尾随空格）。

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会测试渐进式 tab 补全：

```bash
# 注意：下面的提示符行显示在同一行上
$ xyz_<TAB>
$ xyz_foo_<TAB>
$ xyz_foo_bar_<TAB>
$ xyz_foo_bar_baz
```

测试程序会验证：
1. 在 `xyz_<TAB>` 后，补全显示 `xyz_foo`
2. 输入 `_` 并按 tab 后，补全显示 `xyz_foo_bar`
3. 再输入 `_` 并按 tab 后，补全显示 `xyz_foo_bar_baz `，带尾随空格
4. 只有当只剩一个匹配项时才出现尾随空格
