## 处理无效补全

在这一阶段，你将完善 shell 的 tab 补全行为，以处理用户输入无效命令的情况。

### 处理无效补全

当用户输入不匹配任何已知内置命令的命令并按 `<TAB>` 时，你的 shell 应该：

1. 保持输入不变（不要修改用户输入的内容）
2. 按铃以指示没有有效的补全

铃声是通过向终端打印[铃字符](https://en.wikipedia.org/wiki/Bell_character) `\x07` 产生的。根据终端设置，这通常会产生可听到的蜂鸣声或可视闪烁。

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

测试会模拟用户输入无效命令并按 `<TAB>` 键：

```bash
$ xyz<TAB>
$ xyz
```

测试程序会验证：
- 当没有补全可能时输入保持不变
- 铃字符被打印以指示没有匹配
