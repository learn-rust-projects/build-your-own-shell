## 内置命令自动补全

在这一阶段，你将实现对内置命令的自动补全支持。

### Tab 自动补全

Tab 补全是 shell 的一个功能，通过按 `<TAB>` 键帮助用户补全命令。

在这一阶段，你将为两个内置命令实现自动补全：`echo` 和 `exit`。

当用户输入部分命令并按 `<TAB>` 时，你的 shell 应该：

1. 检查部分文本是否匹配内置命令的开头（特别是 `echo` 或 `exit`）
2. 如果有匹配，补全该词
3. 添加尾随空格，以便用户可以立即输入参数

例如，如果用户输入 `ech` 并按 tab，你的 shell 应该将其补全为 `echo `（末尾有空格）

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会模拟用户输入和 tab 按键：

```bash
$ ech<TAB>
$ echo

$ exi<TAB>
$ exit
```

测试程序会验证：
- 在 `ech` 后按 tab 补全为 `echo `
- 在 `exi` 后按 tab 补全为 `exit `

### 注意事项

- 对于此扩展，在内存中存储历史记录就足够了。跨会话的历史记录持久化将在单独的扩展中实现
