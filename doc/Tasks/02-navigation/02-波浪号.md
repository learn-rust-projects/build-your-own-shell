## cd 内置命令 - 波浪号（~）

在这一阶段，你将扩展 `cd` 内置命令来处理 `~` 字符。

### cd 内置命令（回顾）

作为回顾，`cd` 可以接收多种类型的参数：

- 绝对路径，如 `/usr/local/bin`。（在早期阶段已处理）
- 相对路径，如 `./`、`../`、`./dir`。（在早期阶段已处理）
- `~` 字符。

### 波浪号（~）字符

`~`（波浪号）字符是用户主目录的简写。这是一种方便的方式，可以从文件系统中的任何位置快速导航回主目录。

主目录由 [`HOME`](https://pubs.opengroup.org/onlinepubs/9799919799/basedefs/V1_chap08.html#tag_08_03) 环境变量指定。当你的 shell 看到 `cd ~` 时，它应该：

1. 读取 `HOME` 环境变量的值
2. 切换到该目录

例如：
```bash
$ pwd
/usr/local/bin
$ cd ~
$ pwd
/home/user
$ cd /var/log
$ pwd
/var/log
$ cd ~
$ pwd
/home/user
```

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送一系列 `cd` 命令：

```bash
$ cd /usr/local/bin
$ pwd
/usr/local/bin
$ cd ~
$ pwd
/home/user
$
```

测试程序会验证：
- `cd ~` 切换到主目录
- 主目录与 `HOME` 环境变量的值匹配

### 注意事项

- 大多数语言提供读取环境变量的函数（如 Node.js 中的 `process.env.HOME`、Python 中的 `os.getenv('HOME')` 或 C 中的 `getenv("HOME")`）
