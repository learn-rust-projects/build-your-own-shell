## Cd 内置命令 - 绝对路径

在这一阶段，你将实现 `cd` 内置命令来处理绝对路径。

### Cd 内置命令

`cd`（change directory，切换目录）内置命令用于更改当前工作目录。

`cd` 命令可以处理不同类型的参数：

- 绝对路径，如 `/usr/local/bin`
- 相对路径，如 `./`、`../`、`./dir`
- `~` 字符，代表用户的主目录

在这一阶段，我们专注于绝对路径。

### 处理绝对路径

绝对路径以 `/` 开头，从文件系统的根目录开始指定位置。

当 `cd` 收到绝对路径时：
- 如果目录存在，切换到该目录
- 如果目录不存在，打印 `cd: <directory>: No such file or directory`

例如：

```bash
$ pwd
/home/user
$ cd /usr/local/bin
$ pwd
/usr/local/bin
$ cd /does_not_exist
cd: /does_not_exist: No such file or directory
$ pwd
/usr/local/bin
```

如果目录切换失败，当前目录应保持不变。

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送一系列 `cd` 命令：

```bash
$ cd /usr/local/bin
$ pwd
/usr/local/bin
$ cd /does_not_exist
cd: /does_not_exist: No such file or directory
$
```

测试程序会验证：
- 有效路径会更改目录
- 无效路径会打印错误消息 `cd: <directory>: No such file or directory`
- 无效路径不会更改当前目录

### 注意事项

- 在尝试切换到目录之前检查目录是否存在，或者在切换失败时处理错误
