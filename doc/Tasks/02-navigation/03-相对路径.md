## cd 内置命令 - 相对路径

在这一阶段，你将扩展 `cd` 内置命令来处理相对路径。

### cd 内置命令（回顾）

作为回顾，`cd` 可以接收多种类型的参数：

- 绝对路径，如 `/usr/local/bin`。（在早期阶段已处理）
- 相对路径，如 `./`、`../`、`./dir`
- `~` 字符。

在这一阶段，你将处理第二种参数类型。

### 相对路径

相对路径指定相对于当前工作目录的位置，而不是从文件系统的根目录开始。

你的 shell 必须正确解释和导航相对路径的以下组成部分：

- `./`（当前目录）：指当前工作目录本身
- `../`（父目录）：指文件系统层次结构中当前工作目录正上方的目录
- 子目录：像 `./dirname` 或 `dirname` 这样的路径被视为相对于当前目录

以下是一些示例：
```bash
$ pwd
/usr
$ cd ./local/bin    # 进入当前目录内的 "local/bin"（/usr）
$ pwd
/usr/local/bin
$ cd ../../         # 向上两级
$ pwd
/usr
$ cd local          # "local" 是 "./local" 的简写
$ pwd
/usr/local
```

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会向你的 shell 发送一系列 `cd` 命令：

```bash
$ cd /usr
$ pwd
/usr
$ cd ./local/bin
$ pwd
/usr/local/bin
$ cd ../../
$ pwd
/usr
$
```

测试程序会验证：
- 有效的相对路径正确地更改目录
- 无效的相对路径打印错误消息 `cd: <directory>: No such file or directory`
- 当 `cd` 失败时目录保持不变

### 注意事项

- 实际使用的目录名称是随机的，所以你不能硬编码预期输出
