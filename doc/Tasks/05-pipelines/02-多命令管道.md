## 多命令管道

在这一阶段，你将实现对涉及两个以上命令的管道的支持。

管道可以将多个命令链接在一起，将每个命令的输出连接到下一个命令的输入。

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会发送包含三个或更多阶段管道的命令：

```bash
$ cat /tmp/foo/file | head -n 3 | wc
       3       3      10
$ ls -la /tmp/foo | tail -n 5 | head -n 3 | grep "file"
-rw-r--r-- 1 user user     5 Apr 29 10:06 file
$
```

测试程序会检查多阶段管道执行后最终输出是否与预期输出匹配。

### 注意事项

- 这需要管理多个管道和进程
- 确保正确设置链中每个命令的 stdin/stdout（第一个命令的 stdin 和最后一个命令的 stdout 通常连接到终端或文件重定向）
- 正确的进程清理和等待至关重要
