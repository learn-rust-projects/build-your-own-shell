## 内置命令管道

在这一阶段，你将扩展管道支持以包含 shell 内置命令。

内置命令（如 `echo`、`type`）在作为管道的一部分出现时，无论是在开头、中间还是结尾，都需要被正确处理。

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会发送包含内置命令管道的命令：

```bash
$ echo apple-orange | wc
       1       1      13
$ ls | type exit
exit is a shell builtin
$
```

测试程序会检查管道执行后最终输出是否与预期输出匹配，正确处理内置命令。
对于 `type` 命令，测试程序会检查命令是否正确处理了内置命令并打印了正确的输出，`ls` 输出不应该被打印。

### 注意事项

- 内置命令通常不涉及通过 `fork`/`exec` 创建新进程。你需要在 shell 进程内处理它们的执行，同时仍然管理管道所需的重定向输入/输出
