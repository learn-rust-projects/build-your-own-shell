## 基本管道

在这一阶段，你将实现对涉及两个外部命令的基本管道的支持。

[管道](https://www.gnu.org/software/bash/manual/bash.html#Pipelines) 使用 `|` 操作符将一个命令的标准输出连接到下一个命令的标准输入。

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会执行包含两个命令的多个管道。示例：

```bash
$ cat /tmp/foo/file | wc
       5      10      77
```

```bash
$ tail -f /tmp/foo/file-1 | head -n 5
raspberry strawberry
pear mango
pineapple apple
# (tester appends more lines to /tmp/foo/file-1)
# (And expects the running command to keep printing new lines)
This is line 4.
This is line 5.
$
```

测试程序会检查管道执行后最终输出是否与预期输出匹配。

对于 `tail -f` 命令，测试程序会在管道运行时向输入文件追加内容。

### 注意事项

- 可执行文件（`cat`、`wc`、`tail`、`head`）将在 `PATH` 中可用
- 要执行管道，你需要创建[管道](https://en.wikipedia.org/wiki/Anonymous_pipe)、[fork](<https://en.wikipedia.org/wiki/Fork_(system_call)>)每个命令的进程，并在它们之间设置标准输入/输出重定向
