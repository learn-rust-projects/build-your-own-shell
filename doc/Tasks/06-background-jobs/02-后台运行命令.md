## 后台运行命令

在这一阶段，你将实现后台运行命令。

### 后台作业（回顾）

命令可以通过在末尾添加 `&` 来在后台运行。Shell 启动程序但不等待它完成，允许你继续输入其他命令。

当后台作业启动时，shell 打印一行显示其作业号和进程 ID：
```bash
$ sleep 30 &
[1] 84470
$
```

作业号 `[1]` 从 1 开始顺序分配。每个新的后台作业获得下一个数字。PID（此例中的 `84470`）是操作系统分配的实际进程 ID，会有所不同。

### 使用 `&` 标记运行命令

将命令行解析为标记后，检查最后一个标记是否是 `&`。如果是：
1. 从参数列表中移除它
2. 在后台运行剩余的命令
3. 打印作业号和 PID
4. 立即显示下一个提示符

例如，`sleep 30 &` 有三个标记：`sleep`、`30` 和 `&`。你移除 `&` 并在后台运行 `sleep 30`。

在后台运行命令的具体机制取决于你的语言。例如：
- 在 C 中：调用 `fork()` 和 `exec()` 但不调用 `waitpid()`
- 在 Python 中：使用 `subprocess.Popen()` 而不调用 `.wait()` 或 `.communicate()`
- 在 Node.js 中：使用 `child_process.spawn()` 而不等待进程退出

### 测试

测试程序会这样执行你的程序：
```bash
$ ./your_program.sh
```

然后它会在后台启动一个 sleep 命令：
```bash
$ sleep 500 &
[1] 84470
$
```

测试程序会验证：
- 输出在一行上包含 `[JOB_NUMBER] PID`
- 下一个提示符立即出现（shell 不会等待命令完成）
- 后台进程实际上开始运行

### 注意事项

- 在这一阶段，只启动一个后台作业，所以作业号总是 `[1]`
