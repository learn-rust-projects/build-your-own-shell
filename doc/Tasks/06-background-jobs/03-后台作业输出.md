## 后台作业输出

在这一阶段，你将确保后台作业可以将输出打印到终端。

### 后台作业输出

当命令在后台运行时，后台进程的 stdout 和 stderr 流仍连接到 shell 的终端。这意味着它产生的任何输出仍应出现在你的 shell 中。

例如：
```bash
$ sleep 2 && echo "Done sleeping" &
[1] 84470
$ echo "I can type this immediately"
I can type this immediately
$ Done sleeping
```

这里，作业的输出（`Done sleeping`）出现在终端上，即使它在后台运行。

在这一阶段，你必须确保后台进程共享与 shell 相同的 stdout 和 stderr。在派生后台进程时，让它继承 shell 的 stdio 流。

在大多数子进程 API 中，这是默认行为（例如，Node.js 中的 `stdio: "inherit"`）。

### 测试

测试程序会这样执行你的程序：
```bash
$ ./your_program.sh
```

它将在后台启动一个 cat 命令，然后在读取 FIFO 的前台启动另一个：

```bash
$ cat /path/to/fifo1 &
[1] 84470
$ cat /path/to/fifo2
```

然后测试程序会写入 FIFO：
```bash
$ echo -ne "Hello from FIFO#1\n" > /path/to/fifo1
Hello from FIFO#1
$ echo -ne "Hello from FIFO#2\n" > /path/to/fifo2
Hello from FIFO#2
```

测试程序会验证：
- 后台作业的输出出现在终端上
- 前台作业的输出出现在终端上
- 两个进程共享与 shell 相同的 stdout/stderr

### 注意事项

- 测试程序使用 FIFO（命名管道）来控制输出何时出现。FIFO 是一个特殊文件，在有人写入它之前会阻塞读取
- 确保子进程继承 shell 的 stdio 流
