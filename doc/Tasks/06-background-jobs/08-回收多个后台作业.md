## 回收多个后台作业

在这一阶段，你将处理回收多个后台作业。

### 回收多个后台作业

当几个后台作业正在运行，而其中一些完成时，你的 shell 需要在下一个 `jobs` 调用时检查所有这些作业。

遍历你的后台作业并检查每个作业是否已退出（使用前一阶段中的非阻塞检查）。

与前一阶段一样，每个已完成的作业在 `jobs` 输出中显示状态为 `Done`，然后从作业表中移除。下一个 `jobs` 调用不会再显示那些已完成的作业。它们在被移除前只出现一次为 `Done`。

### 动态标记更新

移除已完成的作业后，应重新计算 `+` 和 `-` 标记。标记始终基于当前作业列表，而不是原始作业号。

标记分配方式回顾：
- 作业号最高的作业获得 `+`（最近）
- 作业号第二高的作业获得 `-`（前一个）
- 所有其他作业获得空格

当作业被移除时，标记会移动：
```bash
$ sleep 100 &
[1] 10886
$ sleep 5 &
[2] 10887
$ sleep 6 &
[3] 10892

# 作业 2 和 3 完成后
$ jobs
[1]   Running                 sleep 100 &
[2]-  Done                    sleep 5
[3]+  Done                    sleep 6

# 下一个 jobs 调用：已完成的作业被移除，作业 1 升格为 +
$ jobs
[1]+  Running                 sleep 100 &
```

作业 1 开始时没有标记（空格），但在作业 2 和 3 被移除后，它是唯一剩余的作业并升格为 `+`。

### 测试

测试程序会这样执行你的程序：
```bash
$ ./your_program.sh
```

然后它会创建后台作业，终止某些作业，然后运行 `jobs` 命令：
```bash
# 启动三个后台作业
$ sleep 500 &
[1] <pid>
$ cat /path/to/fifo1 &
[2] <pid>
$ cat /path/to/fifo2 &
[3] <pid>

# 通过写入其 FIFO 终止作业 2
$ echo -ne "" > /path/to/fifo1

# 检查 jobs - 作业 2 应显示为 Done
$ jobs
[1]   Running                 sleep 500 &
[2]-  Done                    cat /path/to/fifo1
[3]+  Running                 cat /path/to/fifo2 &

# 通过写入其 FIFO 终止作业 3
$ echo -ne "" > /path/to/fifo2

# 检查 jobs - 作业 3 应显示为 Done，作业 2 已移除
$ jobs
[1]-  Running                 sleep 500 &
[3]+  Done                    cat /path/to/fifo2

# 检查 jobs - 作业 2 应被移除，只剩作业 1
$ jobs
[1]+  Running                 sleep 500 &
```

测试程序会验证：
- Done 作业在输出中出现一次，状态为 `Done`
- Done 作业在显示后从作业表中移除
- 每次移除后标记被正确重新计算

### 注意事项

- 遍历所有作业并检查每个作业是否完成。多个作业可能在 `jobs` 调用之间完成
- 作业号是稳定的。作业在其整个生命周期中保持其编号
- 标记始终基于当前剩余作业列表，而不是原始作业号
