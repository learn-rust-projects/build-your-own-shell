## 运行外部程序

在这一阶段，你将添加对运行带参数的外部程序的支持。

### 运行外部程序

到目前为止，你已经实现了 shell 直接执行的内置命令。现在你需要处理外部程序，即你的 shell 需要查找并运行的程序。

当一个命令不是内置命令时，你的 shell 应该：

1. 确定给定的命令是否是一个可执行文件（可以重用 `type` 中的逻辑）
2. 如果是，执行该程序
3. 将命令行中的任何参数传递给程序

例如，如果用户输入 `custom_exe arg1 arg2`，你的 shell 应该：

- 确定 `custom_exe` 是否是 PATH 中的可执行文件
- 用三个参数执行它：`custom_exe`（程序名）、`arg1` 和 `arg2`

### 测试

测试程序会这样执行你的程序：

```bash
./your_program.sh
```

然后它会发送一个你需要执行的命令：

```bash
$ custom_exe_1234 alice
Program was passed 2 args (including program name).
Arg #0 (program name): custom_exe_1234
Arg #1: alice
Program Signature: 5998595441
```

上面显示的输出来自可执行文件本身。你的 shell 只需要运行它并让它的输出显示。

测试程序会验证：

- 你的 shell 正确地查找并执行了程序
- 程序的输出出现在你的 shell 中
- 参数被正确传递

测试程序会运行多个命令，每次使用不同数量的参数。

### 注意事项

- 程序名、参数和预期输出对于每个测试用例都是随机的
- 示例中的输出（"Program was passed N args..."）来自可执行文件。这不是你需要手动实现的东西
- 你需要使用操作系统的 API 来执行外部程序（如 Unix 中的 `exec` 系列、Python 中的 `subprocess`、Node.js 中的 `child_process` 等）
