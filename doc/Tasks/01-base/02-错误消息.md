## 错误消息

在这一阶段，你将实现打印无效命令错误消息的功能。

示例：

```bash
$ xyz
xyz: command not found
```

你的程序应该：

1. 显示提示符 `$ `（保留上一阶段的代码）
2. 读取用户的输入
3. 按照这个格式打印错误消息：`{command}: command not found`
   - 例如，如果用户输入 `xyz`，打印 `xyz: command not found`

目前，我们将所有命令都视为"无效"。在后续阶段中，我们会处理执行"有效"命令，如 `echo`、`cd` 等。
